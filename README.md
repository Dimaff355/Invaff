# Invaff

Минималистичное Android-приложение для анализа инвестиций: собирает портфель из **Т-Банка** и **Финама**
по их API, объединяет одинаковые бумаги и показывает стоимость, прибыль, распределение, графики,
дивиденды, купоны и пассивный доход за выбранный период. Логотипы эмитентов, вход по отпечатку пальца.

- Kotlin + Jetpack Compose (Material 3), minSdk 26
- Без сторонних сетевых библиотек: `HttpsURLConnection` + `org.json`; графики на Canvas
- Токены (используйте только read-only) шифруются ключом Android Keystore и уходят только на серверы брокеров

Сборка: `./gradlew assembleRelease` (JDK 17+).
